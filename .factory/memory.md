# Project memory

Notes the coding agents read before working here. Written by Loopferry when a run learns something,
and yours to edit, reorder or delete at any time.

## Gotchas

- folio/: `npx expo install` silently adds `plugins: ["expo-audio"]` to app.json. Remove it to stay plugin-free for Expo Go. Also, the network can't reach the Expo versions API, so run expo install with EXPO_OFFLINE=1.
- folio/ Playwright QA: reading the Skia WebGL canvas with drawImage/getImageData returns transparent pixels. Sample pixels from page.screenshot instead.

## Decisions

- folio/public/canvaskit.wasm (~8 MB) is gitignored and regenerated by the postinstall `setup-skia-web public`. On web, folio/index.ts loads CanvasKit before requiring App, so any Skia import must stay reachable only from App, never from index.ts top-level.
